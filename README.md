## Project Description

Taskora is a student task management mobile application developed using Flutter and Dart. It helps university students organize their academic tasks, manage deadlines, and keep track of their work.

## Main Features

- Create new tasks.
- View saved tasks.
- Edit existing tasks.
- Delete tasks.
- Store tasks locally using SQLite.
- Organize tasks using categories.
- Select task due dates.
- Local notification reminders.

## Technology Stack

- Flutter
- Dart
- SQLite
- VS Code
- Android Studio
- Git and GitHub

## How to Run the Project

1. Install Flutter and Android Studio.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
flutter pub get
```

5. Connect an Android device or start an emulator.
6. Run Taskora using:

```bash
flutter run -t lib/taskora_sqlite_main.dart
```

## Project Structure

- `lib/` – Application source code.
- `android/` – Android-specific project files.
- `test/` – Application tests.
- `web/` – Flutter web project files.
